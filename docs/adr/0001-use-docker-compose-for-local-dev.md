# 0001. Docker Compose для локальной разработки

## Контекст
Нужен быстрый локальный запуск API + Postgres + Redis на 7,2 ГБ RAM.

## Решение
Используем Docker Compose, а не k8s, на первом этапе.

## Альтернативы
k3d сразу — отклонено: overhead, отвлекает от основ Docker.

## Последствия
+ Быстрый цикл, низкий расход RAM
- k8s-специфика появится позже
