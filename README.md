# Инструкция по сборке и запуску приложения в Docker

В данном руководстве описан процесс сборки Docker-образа для нашего Go-приложения и его последующий запуск в изолированном контейнере.

## Шаг 1. Сборка Docker-образа

Перед сборкой убедитесь, что вы находитесь в корневой директории проекта (там, где расположен файл `Dockerfile`). Для сборки образа выполните следующую команду в терминале:

```bash
docker build -t my-go-app:1.1 .
```

**Разбор параметров команды:**
* `-t my-go-app:1.1` — задает имя образа (`my-go-app`) и его версию/тег (`1.1`).
* `.` — указывает Docker использовать текущую папку в качестве контекста сборки.

## Шаг 2. Запуск контейнера

После успешной сборки приложения вы можете запустить его. Выберите один из двух вариантов в зависимости от ваших целей.

`docker run -d -p 8080:8080 my-go-app:1.1`
